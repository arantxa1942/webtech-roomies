## Structure
webtech-roomies/  
├── photo/                 
├── index.html              
├── user-stories.md                 
├── design-decisions.md     
└── README.md  

- **photo/** is the folder that contains the pictures for the landing page.  
- **index.html** is the code of the landing page, styled with Bootstrap.  
- **user-stories.md** contains the stories that cover the functionality of the app.  
- **design-decisions.md** contains the explanation of the decisions we made while modeling the app.  
- **README.md** contains the structure of the repository, the content of each file, and the link to the domain model.
