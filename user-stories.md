# User Stories

## Roles
1. Visitor
2. Member
3. Moderator

## User Stories

### 1. Browse published listings
As a visitor, I want to browse published room listings, so that I can discover available housing without creating an account.

### 2. Search and filter listings
As a visitor, I want to filter listings by neighborhood, maximum rent, availability date, and amenities, individually or together, so that I can find rooms that meet my needs.

### 3. View room details
As a visitor, I want to view a room monthly rent, deposit, availability date, minimum stay, furnishing, and bathroom arrangements, so that I can see what room suits me.

### 4. View property details
As a visitor, I want to view the properties location, type, bedrooms, bathrooms, shared spaces, and amenities, so that I can evaluate the home surrounding the room.

### 5. Read property reviews
As a visitor, I want to read ratings and comments from people who visited a property, so that I can assess whether it matches the listings.

### 6. Register an account
As a visitor, I want to create a member account, so that I can publish rooms and apply to others listings.

### 7. Log in
As a member, I want to log in to my account, so that I can securely access my listings and applications.

### 8. Log out
As a member, I want to log out of my account, so that other people using the same device cannot access my private information.

### 9. Act as both host and seeker
As a member, I want to publish my own rooms and apply to other peoples rooms using the same account, so that I can act as both a host and a seeker.

### 10. Register a property
As a member host, I want to register a property with its address, neighborhood, property type, number of bedrooms and bathrooms, and shared spaces, so that I can describe the home where I offer rooms.

### 11. Update a property
As a member host, I want to update my property information, so that seekers can access accurate details.

### 12. Create a draft room listing
As a member host, I want to create a private draft listing for each available room with its rental conditions, description, and photographs, so that I can prepare each offer before publishing it.

### 13. Publish a listing
As a member host, I want to publish a prepared room listing, so that visitors can discover it and members can apply.

### 14. Update a listing
As a member host, I want to update my listings rental conditions, description, and photographs, so that the offer accurately represents the room.

### 15. Withdraw a listing
As a member host, I want to withdraw a listing when I stop offering the room, so that seekers no longer apply to an unavailable offer.

### 16. Apply to a listing
As a member seeker, I want to apply to a published listing with an introduction message, my intended move in date, and my intended stay duration, so that the host can consider me as a potential housemate.

### 17. Track my applications
As a member seeker, I want to view my applications, their submitted information, current states, and associated visits, so that I can follow the progress of my housing search.

### 18. Withdraw an application
As a member seeker, I want to withdraw an application, so that the host knows I should no longer be considered.

### 19. Review received applications
As a member host, I want to view the applications received on my listings, including their messages, intended move in dates, stay durations, and states, so that I can assess potential roomies.

### 20. Shortlist an application
As a member host, I want to shortlist an application, so that I can arrange a visit with a promising applicant.

### 21. Reject an applicant
As a member host, I want to reject an applicant, so that the seeker knows they are no longer being considered for the room.

### 22. Accept one applicant
As a member host, I want to accept one applicant and reserve the room, so that the room is committed to a single future housemate.

### 23. Propose a visit
As a member host, I want to propose a visit date for a shortlisted applicant, so that the seeker can see the property.

### 24. Confirm a visit
As a member seeker, I want to view and confirm a proposed visit, so that the host knows I will attend at the arranged time.

### 25 Review a visited property
As a member seeker, I want to leave a rating and a comment after a visit, so that I can tell other seekers whether the property matched what the listing promised.

### 26. Manage saved listings
As a member seeker, I want to save listings and view my saved selection, so that I can keep track of housing options I am considering.

### 27. Report a listing
As a member, I want to report a listing and explain why i report it, so that moderators can investigate it.

### 28. Review and resolve reports
As a moderator, I want to read the reasons provided, and record my decision, so that reports are investigated and their outcomes are tracked.

### 29. Manage neighborhoods
As a moderator, I want to maintain the neighborhood catalog, so that hosts and seekers can select accurate and consistent locations.

### 30. Manage amenities
As a moderator, I want to maintain the amenity catalog, so that hosts can describe property features consistently and seekers can use them in searches.
